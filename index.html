💡 什麼是插入排序？

「把資料分成已排序與未排序，每次把未排序的第一個，插進已排序的正確位置。」

🃏 撲克牌類比

就像整理手牌：一張一張摸牌、比較大小、找到位置後插進去。跟插入排序流程完全一樣！

核心口訣：

  • 1. 最前端先當已排序區。
  • 2. 拿未排序第 1 個，由右往左比。
  • 3. 插到正確位置，重複直到完成。

💻 演算法詳解

  1. 由第 2 個元素開始當作 Key。
  2. 往左掃描已排序區。
  3. 若左邊元素 > Key，則左邊元素往右移。
  4. 直到遇到 ≤ Key 的元素，將 Key 放入空位。
for i = 1 to n-1
  key = A[i]
  j = i - 1
  while j >= 0 and A[j] > key
    A[j+1] = A[j]
    j = j - 1
  A[j+1] = key
