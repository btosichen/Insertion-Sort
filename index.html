插入排序法大挑戰

什麼是插入排序？

就像整理撲克牌！把牌分成「已排序」和「未排序」，每次拿一張未排序的牌，插進已排序的正確位置。

三大規則口訣

  1. 最前端先當已排序
  2. 拿未排序第 1 個當 Key
  3. 從右往左比，插進正確位置

演算法邏輯

for i = 1 to n-1 // 從第 2 張牌開始

key = A[i] // 拿出這張牌 (Key)

j = i - 1 // 準備跟左邊的比

while j >= 0 and A[j] > key

A[j+1] = A[j] // 比 Key 大就往右移

j = j - 1 // 再看更左邊那張

A[j+1] = key // 找到位置，插入！
